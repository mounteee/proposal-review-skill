# Scoring Rubric

每项 1-5 分。评分用于定位短板，不用于制造伪精确感。

## 1. 逻辑严密性

- 5：概念清楚，前提充分，推理链完整，结论边界明确。
- 4：主链成立，有少量概念或边界需要补强。
- 3：大方向可理解，但存在明显跳步或未证明前提。
- 2：关键推理不成立，结论明显超过前提。
- 1：概念混乱或核心论证自相矛盾。

## 2. 证据强度

- 5：关键 claim 均有一手或高可信来源，口径清楚。
- 4：主要 claim 有来源，少数辅助判断需补证据。
- 3：有一些来源，但关键 claim 证据不足或口径不明。
- 2：核心数据、案例、趋势判断缺来源或来源弱。
- 1：大量事实无来源，或证据与结论不匹配。

## 3. 框架清晰度

- 5：结构服务目标，层级清楚，读者能快速抓住主线。
- 4：结构基本清楚，局部顺序或层级可优化。
- 3：信息齐全但组织松散，主次不够明显。
- 2：框架堆概念，读者难以判断重点。
- 1：结构混乱，无法支撑结论。

## 4. 受众说服力

- 5：准确回应目标受众的动机、疑虑和决策标准。
- 4：能说服大部分目标受众，但反对意见处理不足。
- 3：表达清楚，但更多是作者视角，不完全贴合读者。
- 2：读者难以理解为什么与自己有关。
- 1：受众、利益和行动路径都不清楚。

## 5. 策略可执行性

- 5：动作、资源、时序、责任、指标、风险都清楚。
- 4：主要动作可执行，少数资源或指标需补充。
- 3：方向可行，但缺少关键落地条件。
- 2：建议停留在概念层，执行路径模糊。
- 1：无法判断如何执行，或执行条件明显不成立。

## 6. 风险意识

- 5：识别主要反例、失败条件、替代解释，并有应对。
- 4：覆盖主要风险，但深度不足。
- 3：提到风险，但未影响方案设计。
- 2：风险处理表面化。
- 1：基本没有反方视角或失败条件。

## Final verdict rules

不要简单平均。按短板决定最终结论：

- `可发布`：所有维度 ≥ 4，且无关键证据缺口。
- `小修后可用`：最低分 ≥ 3，问题主要是结构、表达或局部证据。
- `需大修`：任一核心维度为 2，或证据强度 ≤ 2。
- `不建议发布`：逻辑严密性 ≤ 2 且证据强度 ≤ 2，或方案可能导致重大误导。

## Priority rules

Top 问题排序优先级：

1. 会导致错误决策的问题。
2. 会被读者直接质疑的问题。
3. 会影响转化或行动的问题。
4. 会造成执行失败的问题。
5. 纯表达和风格问题。
